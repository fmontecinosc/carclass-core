# Carclass Core

CRM y sistema de gestión de Carclass Group. El contexto completo para continuar el desarrollo está en `CLAUDE.md`.

## Cómo abrirlo en Claude Code

1. Descomprime esta carpeta en tu computador, por ejemplo en `Documentos\carclass-core`.
2. Abre la app de escritorio de Claude, entra a **Code** y elige esa carpeta.
3. Primer mensaje sugerido: «Lee CLAUDE.md y sigue con la Fase 3: la app estilo Asisma en verde Rolex».

La carpeta `.secrets/` contiene claves privadas. No la compartas ni la subas a ningún repositorio público.
